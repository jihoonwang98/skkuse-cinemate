# MovieLens 데이터셋 설명

이 문서는 Cinemate에서 사용하는 MovieLens 데이터셋의 주요 파일과 역할을 설명한다.

## 주요 파일

| 파일                  |      용량 | 역할                             |
| ------------------- | ------: | ------------------------------ |
| `genome-tags.csv`   |  약 18KB | 추천에 사용할 태그 목록                  |
| `genome-scores.csv` | 약 522MB | 영화별 태그 관련도 점수                  |
| `links.csv`         | 약 1.9MB | MovieLens 영화 ID와 TMDB 영화 ID 연결 |
| `ratings.csv`       | 약 934MB | 영화별 평점 수와 평균 평점 계산             |

-> Supabase Free tier 용량은 대략 500MB이므로, 인기순으로 3000개의 영화만 선별하는 과정이 필요했다.

## `genome-tags.csv`

MovieLens에서 정의한 영화에 대한 Tag 목록이다.

```csv
tagId,tag
1,sci-fi
2,cyberpunk
3,action
4,romance
```

## `genome-scores.csv`

영화별로 각 MovieLens 태그와 얼마나 관련 있는지 나타내는 점수 데이터다.

예를 들어 The Matrix가 `sci-fi` 태그와 0.95만큼 관련 있고, `cyberpunk` 태그와 0.91만큼 관련 있다는 식의 점수를 제공한다.

```csv
movieId,tagId,relevance
100,1,0.95
100,2,0.91
100,3,0.72
100,4,0.12
```

## `links.csv`

MovieLens의 `movieId`와 TMDB의 `tmdbId`를 연결하는 파일이다.

Cinemate의 movie id는 TMDB id를 사용한다. 따라서 MovieLens에서 찾은 추천 후보를 Cinemate의 영화 데이터와 연결하려면 `links.csv`가 필요하다.

`imdbId`도 포함되어 있지만 사용하지는 않는다.

```csv
movieId,imdbId,tmdbId
100,0133093,603
```

## `ratings.csv`

사용자 평점 데이터다.

`rating`은 사용자가 남긴 별점이다. 0.5가 최소값이고 0.5 단위로 증가하며, 5.0이 최대값이다.

```csv
userId,movieId,rating,timestamp
1,100,5.0,1225734739
2,100,4.5,1225865086
```


## 사용하지 않는 파일

### `movies.csv`

`movies.csv`는 영화 제목(`title`)과 장르(`genres`)만 제공하므로 Cinemate에서 필요한 상세 정보를 구성하기에는 충분하지 않다. Cinemate는 이 파일의 영화 정보를 사용하지 않고, TMDB를 기준으로 영화 상세 정보를 가져와 구성한다.

### `tags.csv`

`tags.csv`에는 MovieLens가 공식적으로 정의한 태그가 아니라 사용자가 영화에 직접 등록한 태그가 담겨 있다. Cinemate의 태그 기반 추천에는 `genome-tags.csv`와 `genome-scores.csv`를 사용하므로 `tags.csv`는 사용하지 않는다.
