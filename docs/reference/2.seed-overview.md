# 데이터 사전 Seed

## 1. 데이터 출처와 역할

| 데이터 출처 | 역할 |
| --- | --- |
| MovieLens | 서비스 대상 영화 후보, 사용자 평점, 영화 간 추천 관계, Tag Genome |
| TMDB | 영화 제목, 줄거리, 포스터, 장르, 배우와 제작진 등 상세정보 |
| 영화 대본 | 캐릭터 성격과 말투, 주요 사건, 대화 시작 질문 등 캐릭터 채팅 콘텐츠 구성 |

MovieLens는 추천에 필요한 사용자 반응 데이터를 제공하지만 영화 상세정보는 제한적이다. 따라서 영화의 상세정보는 TMDB를 기준으로 보완한다.

## 2. Seed 데이터 구성 영역

### 영화 상세정보

MovieLens와 TMDB가 연결된 영화 중 서비스에 필요한 상세정보가 충분한 영화를 선정한다. 영화의 화면 표시 정보와 장르는 TMDB를 기준으로 구성한다.

구성된 영화 상세정보와 장르, 배우·제작진 정보는 `movies`, `genres`, `movie_genres`, `people`, `movie_casts`, `movie_crew` 테이블에 저장한다.

### 영화 간 유사도

MovieLens 사용자 평점을 바탕으로 여러 사용자가 함께 높게 평가한 영화 간의 유사도를 미리 계산한다. 런타임에서는 이 결과를 사용자의 선호 영화와 조합하여 추천 영화를 조회한다.

계산된 영화별 평점 통계와 영화 간 유사도는 각각 `movie_stats`, `movie_similarities` 테이블에 저장한다.

### 추천 채팅

MovieLens Tag를 이용해 영화가 특정 주제나 분위기와 얼마나 관련 있는지 구성한다.
사용자 자연어와 MovieLens 태그를 의미적으로 연결할 수 있도록 태그별 embedding을 추가하여, 정확히 같은 단어가 아니더라도 의미가 유사한 영화 태그를 찾을 수 있게 한다.

태그와 영화별 관련도, 태그 embedding은 `movie_tags`, `movie_tag_relevances`, `movie_tag_mapping_embeddings` 테이블에 저장한다.

### 캐릭터 채팅

캐릭터의 성격, 말투, 주요 사건에 대한 관점과 기본 질문은 MovieLens나 TMDB에서 자동으로 가져오는 정보가 아니다. 영화 대본을 참고하여 작성하고, 영화 및 배우 정보와 연결되는 캐릭터 채팅 콘텐츠로 구성한다.

캐릭터 채팅 콘텐츠는 `characters`, `character_chat_events`, `character_chat_event_participants`, `character_chat_default_questions` 테이블에 저장한다.
